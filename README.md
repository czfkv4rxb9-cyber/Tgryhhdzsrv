# Pocket Python

Редактор Python в браузере: подсветка синтаксиса, автодополнение, выполнение
кода через [Pyodide](https://pyodide.org/) и модуль `turtle`, нарисованный на
canvas с зумом и панорамированием. Устанавливается как приложение на iOS,
iPadOS, Android и десктоп.

## Что умеет

- Запуск Python прямо на устройстве — без сервера, `print()`, `input()`,
  трассировки ошибок.
- `turtle` целиком в браузере: перо, заливки, окружности, текст, зум и
  перетаскивание холста. Поддержаны короткие псевдонимы (`fd`, `lt`, `rt`, `pu`,
  `ht`, `seth`…), цвета кортежами с `colormode`, запросы состояния (`xcor`,
  `heading`, `distance`, `isdown`) и `numinput` / `textinput`.
- Открытие и сохранение `.py`-файлов.
- Ссылка на свой код: снимок прямо в адресе страницы или живой показ,
  когда учитель видит набор текста, консоль и рисунок черепахи в реальном
  времени.
- Проверка кода нейросетью с автоматическим исправлением — на бесплатных моделях OpenRouter.
- Работа офлайн после первого запуска (service worker кэширует и Pyodide).

## Установка на iPhone / iPad

Откройте сайт в Safari → «Поделиться» → «На экран «Домой»».
Приложение запустится на весь экран, с адаптированной под тач раскладкой:
редактор во всю ширину, нижняя навигация и ряд клавиш с отступом и скобками,
которых нет на экранной клавиатуре iOS.

## Проверка кода через ИИ

Кнопка 🔑 в панели сохраняет ваш [API-ключ OpenRouter](https://openrouter.ai/keys)
(`sk-or-v1-…`) в `localStorage` — **только в вашем браузере**, он никуда не
передаётся, кроме `openrouter.ai`, и не попадает в этот репозиторий.

Запрос идёт на `https://openrouter.ai/api/v1/chat/completions` и использует
**только бесплатные модели** — платить за проверку не нужно, ключ нужен лишь
для доступа к API.

Список задаётся константой `AI_MODELS` в `index.html` и перебирается по
порядку, пока какая-нибудь не ответит:

| Модель | Что это |
|---|---|
| `openrouter/free` | роутер OpenRouter, выбирает бесплатную модель случайно |
| `poolside/laguna-s-2.1:free` | агент для кода, 262k контекста |
| `cohere/north-mini-code:free` | тоже заточена под код |
| `nvidia/nemotron-3-super-120b-a12b:free` | запасная |

Перебор нужен потому, что у бесплатных моделей жёсткие лимиты и одиночная
модель регулярно отвечает `429`. Какая именно модель ответила, приложение
пишет в консоль. Актуальный список бесплатных моделей —
на [openrouter.ai/models](https://openrouter.ai/models?max_price=0).

Ключ виден любому коду, выполняющемуся на странице. Это неизбежно для
приложения без серверной части — поэтому задайте ключу
[лимит расходов](https://openrouter.ai/settings/keys) (при бесплатных моделях
можно поставить нулевой) и не вводите его на чужой копии сайта.

## Поделиться кодом

Кнопка «Поделиться» даёт две ссылки, обе работают без сервера и без регистрации.

**Ссылка-снимок** — код целиком упакован в адрес (`#code=…`, сжатие
`deflate-raw` плюс base64url). Открывший её получает код в редакторе и может
его править и запускать: это уже его копия. Работает всегда, в том числе когда
автор офлайн, но показывает код таким, каким он был в момент создания ссылки.

**Живой показ** — пока страница открыта, учитель по ссылке `#watch=…` видит в
реальном времени то, что набирает ученик: сам код, вывод консоли, рисунок
черепахи и переключение вкладок. Редактор у смотрящего только для чтения,
кнопки запуска и ИИ-проверки скрыты, а «Открыть как свою копию» превращает
просмотр в обычный редактор.

Связь идёт напрямую между браузерами (WebRTC DataChannel, шифрование DTLS).
Через публичный брокер [PeerJS](https://peerjs.com) проходит только обмен
адресами для установки соединения — код через него не идёт. Если сеть
запрещает прямое соединение, подключается бесплатный ретранслятор на портах
80/443, который видит лишь шифрованный поток.

Чего живой показ не умеет:

- Нужно, чтобы **оба были онлайн одновременно** — трансляция живёт, только пока
  открыта страница ученика.
- **Любой, у кого есть ссылка, видит код.** Ссылка — это и есть пароль.
- В строгих школьных сетях соединение может не установиться вообще; через 20
  секунд приложение честно об этом сообщит и предложит ссылку-снимок.
- На iOS свёрнутая вкладка может приостановить соединение — после возврата оно
  восстанавливается само.

Ссылка-снимок — запасной вариант на все эти случаи.

## Локальный запуск

```bash
python3 -m http.server 8765
```

Затем откройте http://localhost:8765.

## Оформление

Интерфейс собран по дизайн-системе **Nocturne**: тёмная почти нейтральная
сине-серая основа `#161826`, Inter средним начертанием, радиусы 8px и один
акцент `#9184d9`, который живёт в линиях, свечении и рамках, а не в заливках —
кнопки везде контурные. Иконки — [Phosphor](https://phosphoricons.com). Холст черепахи тоже тёмный:
сетка и перо по умолчанию берут цвет от яркости фона, поэтому `bgcolor("white")`
переключает их обратно на тёмные.
Все цвета, шрифты и радиусы вынесены в CSS-переменные в начале `index.html`;
хардкоженых значений в разметке нет.

Иконка приложения — ступенька: одновременно свернувшаяся под прямыми углами
змея и отступ в питоновском коде. Читается на 32 px и переживает маску Android
(для неё лежат отдельные full-bleed варианты `icon-maskable-*`).

## Как устроено

Файлы, без сборки и зависимостей:

| Файл | Назначение |
|---|---|
| `index.html` | Приложение целиком: разметка, стили, редактор, `turtle`-шим для Pyodide |
| `sw.js` | Service worker: кэш оболочки и рантайма Python для офлайна |
| `manifest.json` | Манифест PWA |
| `apple-touch-icon.png` | Иконка для экрана «Домой» в iOS (непрозрачная, без своего скругления — iOS накладывает маску сама) |
| `icon-*.png` | Иконки для манифеста: `any` со скруглением и `maskable` во всё поле |
